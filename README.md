I)
To access the datas from the database via the API you must first enable Backend in the "/Backend" repertory :
enter the following command in the terminal :
"npm start"

II)
To open the files and access to the content of the website you must enable an http server instance :
1) In parallel of your Backend, open another instance of your IDE or terminal, and go to the "/Frontend" repertory,
2) enter the following command : 
"npx http-server -p 5500"

It will enable the server to acces the website on the following HTTP adress :
"http://localhost:5500"

enter the adress in your browser URL
