
# Sophie Bluel - Portfolio d'architecte d'intérieur

Projet réalisé dans le cadre de la formation Développeur Web d'OpenClassrooms : création d'une page web dynamique en JavaScript, connectée à une API.

## Technologies
JavaScript, HTML, CSS, API REST (Node.js)

## Lancer le projet en local

1. Démarrez le back-end (API) :

        cd .\Backend\
        npm install
        npm start

2. Dans un second terminal, démarrez un serveur HTTP pour le front-end :

        cd FrontEnd
        npx http-server -p 5500

3. Ouvrez http://localhost:5500 dans l'url du navigateur.
